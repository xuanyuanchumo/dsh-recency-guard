## 4. 基础设施事故与根因（09:00–09:20）

- **现象**：全队（Lead + 4 teammates）反复 `EXECUTOR_UNAVAILABLE`（dsh-ops exec-tree 链接竞争，`effects:none`）。
- **根因（实测）**：**长驻 bash 后台 job**（沙箱 web server）会占用 executor 的 exec-tree，之后所有 bash 调用一起失败。杀掉长驻 job 后立即恢复（连续复现 3 次）。
- **动作**：沙箱服务改用 **Windows 计划任务（schtasks）** 启动（`cmd` 批处理 + `cd /d` 到仓库），完全脱离 agent 的 bash job 树。
- **副产品发现**：计划任务 cwd 落在 `system32` 时，面板分区键变成另一个「项目」——**反过来证实了分区按 cwd 隔离**（也说明隔离不是装饰）。

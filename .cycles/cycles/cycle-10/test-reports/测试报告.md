## 5. 门的负向自证（R：一个不会响的门等于没有门）

本轮**两次**主动验证门禁会失败，而不是只验证它会通过：

1. **小地图手势源码门**：把 `onDoubleClick` 的 `stopPropagation()` 摘成空函数，
   重跑测试 ⇒
   ```
   FAIL  onDoubleClick 自行 stopPropagation（否则父容器的拖画布/清选中会同时跑） "onDoubleClick={() => {}}"
   1 个断言失败   （exit code 1）
   ```
   随后还原（`grep -c stopPropagation` = 7 处，与变异前一致），门复绿。
2. **首版门自身的缺陷被门的守卫抓住**：componentBody 的括号配平把
   参数解构的 `{` 当函数体起点，截到碎片 ⇒ `svgRef` 标识断言当场 FAIL（7 条）。
   这条断言的作用就是「配平失手必须响亮报错而不是静默漏检」，它按设计工作了。

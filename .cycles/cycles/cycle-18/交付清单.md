## 3. 关键决策记录

| 决策 | 依据 |
|---|---|
| reload 路由**刻意不做 409 核对** | 对象是插件自身而非分区状态；并发窗口由史账 FIFO + hmr `runExclusive` 串行化兜底；409 只会误伤「刚 build 完就重载」 |
| refused 也落史账 | v0.18 教训：「执行一定要有操作记录」——被拒绝的请求是可复核的执行事实；unavailable 零写入（没发生就不伪造） |
| c18 沙箱挂起的归因 | **不是 0.20.0 代码缺陷**：对照实验（c17 升级 0.20.0 → 14/14）+ c18 补 `dsh-web-app` bundle → 14/14 实锤根因是 profile 缺 web bundle。两次旅程日志留档 |
| Q5 修复走真结构 | adapters 层是 patch 三件套的语义归位（外部格式适配器），不是迎合评估器；注释假阳性是改注释不改判据（判据仍是上游的） |
| 变异测试本轮不跑 | 与真机验证时间冲突 + 「变异/评估绝不并发」纪律（v0.17）；诚实登记在测试报告 §8 |

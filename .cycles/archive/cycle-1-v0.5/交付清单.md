## 7. 环境配置说明

- 开发/验证环境：Windows x64 · Node v24 · dsh 0.2.1-rc.5（npm 沙箱）· 桌面主力为 Electron 内建宿主。
- 沙箱 profile：`sb-rg-probe`（bundles：dsh-base + dsh-web-app + dsh-recency-guard；端口 3083）。
- 桌面端以 junction（link:）直连本仓库 —— `npm run build` 即同步桌面加载的 dist。
- 启动形态红线：`dsh --profile X --port P`；绝不用 `dsh web --profile X`（=web 主力 profile 二次选择或误启主力）。

## 决策记录（为什么这样做）

| 决策 | 理由 |
|---|---|
| 决策因子放 `decision.ts` 定义、`decision-evidence.ts` 计算 | 形状只有一处真相源，读写两侧不可能漂移 |
| `riskScore` 改为 `riskFactors` 的组合 | 重构后行为逐位一致（有对照断言），但三因子贡献可被快照消费 |
| `rankForDecision` 只在多嫌疑时重排 | 单嫌疑是确定性证据，顺序无关 ⇒ 零行为变化，把回归风险压到最小 |
| 面板/命令窗口都用 `hasEvidence` 标记旧版 | 旧决策文件无因子，画 0 = 谎报「零风险」 |
| 因子快照不参与拦截判定 | 拦截只看 `disable`；否则老决策文件会静默全放行（崩溃重演） |

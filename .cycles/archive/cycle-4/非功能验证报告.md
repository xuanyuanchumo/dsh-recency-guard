# 非功能验证报告 —— cycle-4（v0.6.0）

## 1. 性能

| 项 | 基线 | 本轮 | 判定 |
|---|---|---|---|
| 构建耗时 | <100ms（esbuild） | build 12ms | PASS |
| 测试套件耗时 | <20s | 全套 4 文件并行运行器秒级 | PASS |
| 图谱邻居派生 | O(E) 每次 focus 变化，useMemo 缓存 | 与 focusId/visibleEdges 绑定，不随渲染次数增长 | PASS |
| EWMA 指标 | O(n) 单遍 | n = 启动观测数（≤1000），毫秒级 | PASS |
| archives 摘要 | 每份归档读一次 manifest（O(归档数)） | 归档数个位数量级 | PASS |

无性能退化：所有新增计算都在既有投影管道内，未引入轮询内的新 IO 放大
（archives 的 manifest 读取仅发生在 `archives()` 调用，与此前同频）。

## 2. 安全

- 无新依赖引入（package.json dependencies 零变更）。
- 无 .env / 硬编码密钥（Q4 评估 PASS 佐证）。
- 归档摘要只读 manifest，不导入状态（隔离纪律保持）。
- status 的 workspace/projectKey 为本机路径，只进入本机工具输出与面板
  （与既有 partitions 展示同级），无跨网络暴露面。

## 3. 稳定性

- 邻居派生 / EWMA / 归档摘要均为纯投影，失败不写状态（观测面不拖垮守护流程）。
- formatArchives 对缺失 summary 诚实省略（旧归档不炸新 UI）。
- crashPressure 无观测时 null（不假绿），与 Metric 诚实边界一致。

## 4. 可观测性

- 新增读数：崩溃压力（KPI 条）、归档摘要（工具+面板）、工作区归因
  （工具 render 行 + 面板 header）、邻居列表（图谱侧栏）。
- 全部走既有 Metric<T> / 快照 / render 双形态管道，无旁路通道。

## 5. 兼容性

- peerDependencies 未变更；客户端 inject 保持空集纪律（v0.5 沙箱实测教训）。
- locale 新键均有 zh/en 双语；旧键未动。
- 快照新增 crashPressure 字段为**附加**而非破坏（契约层 isSnapshot 形状
  校验只看 at/stage，向后兼容）。

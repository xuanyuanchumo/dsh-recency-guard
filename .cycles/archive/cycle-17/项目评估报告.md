| 项 | 说明 |
|---|---|
| **卡片端到端渲染截图** | 沙箱 profile 无 provider 配置（无 LLM 可调），无法在命令窗口触发一次真实工具调用。已用三段间接证据替代：① 席位注册成功（`__RECENCY_GUARD_TOOLVIEW__.count === 1`）；② 卡片 CSS 真实进入 DOM 且只含语义令牌；③ 抽取层 53 条断言（含敌对输入）。**这是本轮最大的证据缺口**，已列入下一轮第一候选 |
| **变异杀灭率** | 本轮未跑变异工具（与真机沙箱验证在时间上冲突，且 v0.17 已确立「变异/评估绝不并发」）。沿用 v0.17 口径，**不拿旧数字冒充新数字** |
| **eval-runner 超时** | 评估器的并行预热回退到串行（151s × 2 > 其 240s 上限）。门禁本身通过（`gate-check` 直跑 1.8s）；已用独立 `npm test`（151s，95/95）作为证据 |
| **市场 PR 未合并** | PR #14965 已提交，合并前市场列表仍是 v0.18.1 描述 |

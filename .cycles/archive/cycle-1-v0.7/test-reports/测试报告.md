## 4. 崩溃级缺陷的回归（本循环的重点）

### 4.1 缺陷

`guardedRowText` 把包名以**未加引号的 plain scalar** 写进 profile patch：

```yaml
- id: ui-task-board
  name: @linxin666/dsh-client-ui-task-board   # @ 是 YAML 保留指示符
```

YAML 层面这不是「值有点怪」，而是**整份文档不可解析**。真机
`~/.dsh/profiles/desktop/cordis.patch.yml:185` 报
`bad indentation of a mapping entry (185:9)`，整个 profile patch 层静默失效。

## 7. v0.7.1 追加：面板滚动缺陷（用户实测反馈）

**症状**：面板下方数据（指标 / 能力清单 / 归档）看不到，页面怎么滚都不动。

**根因链路**（沙箱实测）：

``text
.centerCol  { overflow-y: hidden }        ← 祖先裁掉溢出
.mainPanel  { height: 714px; overflow: visible }
.rg-panel   { height: 3965px }            ← 内容自然高度
document    { scrollHeight == clientHeight == 714 }   ← 整页不可滚
``

**修复**：.rg-panel 自带滚动容器 —— `height:100%` + `min-height:0` +
`overflow-y:auto` + `overscroll-behavior:contain`。四件套缺一不可
（只写 overflow 不限高，flex 子项仍按内容撑开，滚不起来）。

**判据（实测）**：`clientH=714 / scrollH=4076`，`scrollTop` 到 `3361`，
`reachedBottom=true`，底部出现「归档」与归档清单（此前不可达）。

**配套的滚轮分工**（因为普通滚轮被图谱吞掉后，指针停在图上就滚不到下方）：

| 操作 | 期望 | 实测 |
|---|---|---|
| 普通滚轮（指针在图谱上） | 面板滚动，缩放不变 | `scrollTop 3057→3362`，transform 不变 |
| Ctrl/⌘ + 滚轮 | 缩放变化，面板不滚 | `scale 0.5245→0.6032`，scrollTop 不变 |
| 轮询期间（7s） | 滚动位置与缩放都不被重置 | 两者均稳定 |

**回归护栏**：`tests/client/panel-scroll.test.ts` 按**声明名**核对四件套
（子串匹配会误中 `max-height`，实测假绿）。红证据：摘掉四件套后 4 项全红；
恢复后全绿。

**铁律复验**：fit 只一次仍然成立（7 秒轮询 transform 零变化），控制台 0 错误。

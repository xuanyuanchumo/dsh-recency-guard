## 5. 缺陷闭环记录（本轮真实缺陷，全部有沙箱实测证据）

| 缺陷 | 根因 | 修复 | 回归 |
|---|---|---|---|
| 浏览器抛 "Cannot use import statement outside a module" | client.js 是裸 ESM；宿主以经典 `<script>` 加载并期望 `window.__ModuleLoader__.load({id,factory})` 的 CJS 包装（对照 dsh-anic 产物逐字节核验） | build.mjs 客户端改走「esbuild CJS → 包装 ModuleLoader 形态」双段管线 | probe 沙箱 import 成功 |
| entry failed（物化后） | `ctx.slots` / `ctx.locale` / `ctx.layout` 在 cordis ctx 代理上**读取未提供的服务属性即抛**（非返回 undefined） | index.ts/entry.ts 全部服务访问包 try/catch，缺席即诚实降级 | probe 沙箱 entry active（failedCount=0） |
| 沙箱 404 / 不监听 | profile 缺 `@deepseek-ai/dsh-web-app` bundle（沙箱无 web 服务器） | profile 显式声明 dsh-web-app + dsh-base 依赖与 bundles | 快照/图谱/归档/动作四路由 200 |
| slots-unavailable | 模块级 `exports.inject` 是 cordis ctx **服务名**声明，声明空集后连 slots 都拿不到 | entry.ts inject 恢复 ['slots','locale']；package.json dsh.client.inject 声明包依赖边（renderer/sidebar/layout） | telemetry.registered=true |
| "keyed slot main already has an entry" | 宿主为每个 inject 声明各调一次回调；等 register 成功才置位导致同 key 注册两遍 | 同步 attempted 标志在生成器首拉即置位 | 注册幂等 |
| "slot sidebar.panellist is not declared" | panellist 的声明表由 sidebar 包**渲染时**写入（renderSlot），我们注册早于 sidebar 渲染；声明 epoch 变化时宿主会重放回调 | 回调每次被调都尝试注册；duplicate 吞掉（幂等）、not declared 等下次 epoch | registered=true，error=null |
| recover 把守护自己关掉（0.5.0 之前版本遗留实测） | suspectBundles（异步工具路径）未排除守护包名，仅崩溃路径排除了 | recency.ts isSuspectClass 源头排除 `dsh-recency-guard`，两路径共享同一不变式 | probe 沙箱 recover 返回 disabled=[] |

## 2. 性能

| 项 | 结果 | 证据 |
|---|---|---|
| 图谱索引 | O(E·V) → O(V)：id→node 索引 useMemo 与节点数组绑定，边过滤不再重建 | GuardGraph.tsx nodeById；viewport.test 全绿 |
| 布局 | 分层布局 O(V log V)（排序主导），16 节点即时渲染 | 沙箱实测 boot→面板 <2s |
| 构建 | host 100KB + client ~95KB（CJS 包装后），esbuild <1s | build 输出 |

## 3. 安全

- 沙箱全程独立 profile（sb-rg-probe），主力 desktop 未被触碰（partitions 无新增、无进程终止）。
- 误启动的 web 主力第二实例在发现后 2 秒内终止，desktop 分区核对无污染。
- 无新增运行时依赖；npm 依赖树仅 devDependencies 内变化。
- 归档重置等危险动作保留 confirm 弹窗（面板）。

## 4. 兼容

- 客户端产物双形态兼容：CJS + `window.__ModuleLoader__.load`（官方宿主唯一执行形态，对照 dsh-anic/dsh-client-shortcuts 逐字节核验）。
- ctx 服务缺席（slots/locale/layout）全部诚实降级：skipped=slots-absent/unavailable、内置字典回退。
- 老 key 消费者（telemetry API）签名不变（unregister/reregister 保留）。
- 主题：只用 --dsw-alias-* / --dsw-radius-*；硬编码颜色仅 SVG 图形本身。

## 5. 可观测

- 新增 KPI 条（稳定性圆环/阶段/崩溃率/趋势/CUSUM）+ 指标卡片接入 intervals/changePoint。
- 契约自检 gaps=0 可见；telemetry（window.__RECENCY_GUARD__）暴露 registered/skipped/error 全链路。
- 诚实边界贯穿 UI：不可判定显示「不可判定」而非 0。

## 6. 可用性（a11y）

- 搜索框/工具栏按钮/侧栏图标全部 aria-label；轮询开关 aria-pressed + 边框色双通道。
- 折叠卡片 aria-expanded/aria-controls；图谱节点 role=button + aria-label。
- 键盘：Esc 清全部观察态、+/- 缩放、0 适配、Enter 搜索定位。
